# Blender 白膜运镜工作室

## 默认行为

- 以 `D:\blender.exe --background --factory-startup` 运行 Blender 5.2 LTS，不启动 Launcher，不显示窗口，不抢焦点。
- 只有用户明确要求打开 Blender 界面时才前台运行。
- 固定执行顺序：场景白膜 → 人物白膜与接触关系 → 运镜。前一阶段未通过不得进入后一阶段。
- 默认交付可编辑 `.blend`。摄影机、场景、骨骼、运动 Curve、注视 Curve 与关键帧都必须保留。
- Blender 无法完成某项能力时，才使用 `$storyboarder-whitebox-scene`；切换前说明失败点，不能悄悄降级。

## 文件纪律

每个任务新建一个中文项目文件夹，放在：

```text
D:\余晓文\02_Codex功能\Blender白膜运镜工作室\03_正式项目\项目名/
├─ 01_参考资料/
├─ 02_输入规格/场景与运镜规格.json
├─ 03_Blender项目/项目名.blend
├─ 04_机位截图/
├─ 05_运镜轨迹与预览/
├─ 06_质量测试/Blender构建报告.json
└─ 07_生图提示词/逐镜最终生图提示词.md
```

开发验证放 `02_开发测试`，正式任务放 `03_正式项目`。不得把输出散落到桌面、磁盘根目录、Blender 安装目录或 Skill 根目录。参考图片、视频和文字说明先复制到本项目 `01_参考资料`；不删除用户源文件。

## 1. 需求转三维规格

1. 完整理解参考图/文字中的场景拓扑、人物关系、尺度、遮挡、前中后景和所有高低差；不得把单张图当平面贴纸照抄。
2. 建立 X=左右、Y=纵深、Z=高度、单位米的坐标系。记录平台顶面、坑底、台阶、坡面、楼层和落差。
3. 用 box、cylinder、sphere、wedge/ramp 搭建叙事必要轮廓；车辆、建筑和复杂物体用组合体，不追求材质细节。
4. 把需求写成 `references/studio-spec-schema.md` 所定义的 JSON。

## 2. 先搭建场景

- 先创建固定场景、地面、建筑、道具和遮挡体；按层级检查高度和行走面。
- 先用正视、侧视、顶视核对拓扑，再放人物。
- 场景与角色分集合保存，中文命名，不能把整个项目合并成不可编辑网格。

## 3. 再放置可摆姿势人物

- 使用 `assets/人物白膜/adult-male.glb` 与 `adult-female.glb` 的官方 Storyboarder 67 骨骼模型。
- 主要角色按首次出现顺序使用不同纯色；次要角色统一灰色。
- 支持 `stand relaxed`、`sit chair`、`confrontation/gesture` 预设；复杂姿态使用 `bone_rotations` 和 `bone_locations` 微调。
- 必检：脚底贴地、坐姿骨盆落在椅面、膝脚方向成立、手与道具接触、人物不穿墙/桌/彼此、朝向与叙事目标一致。

## 4. 机位必须叠加

- 始终自动保留正视、左侧视、右侧视、背视、顶视五个基础相机。
- 用户提供 N 个镜头，就在五个基础相机之外新增 N 个剧情相机；绝不替换基础相机。
- 每个剧情相机按镜号中文命名并渲染对应截图。先检查起始构图，随后才允许创建运镜。

## 5. 文字运镜与沿轨迹运动

- 把推、拉、摇、移、升降、环绕、跟拍、手持和焦段变化转成 `motions[].keyframes`。
- 每条 motion 创建两条 Bezier Curve：摄影机 `运动轨迹` 与目标 `注视轨迹`。
- 摄影机通过 Follow Path 绑定运动轨迹，通过 Track To 看向沿注视轨迹运动的 Empty。
- 用户画的轨迹必须保持可编辑；自动化优先修改曲线控制点，不烘焙成无法回改的逐帧位移。
- 使用 `scripts/run-blender-whitebox.ps1` 隐藏生成项目、截图和视频。

## 6. 参考视频运镜复刻

1. 把参考视频复制到项目 `01_参考资料`。
2. 运行 `scripts/extract-reference-video.ps1`，抽帧结果放 `05_运镜轨迹与预览/参考视频分析`。
3. 检查切镜；每个连续镜头必须拆成独立 motion。
4. 依据起止构图、主体屏幕位置、景别、水平/垂直视差、运动方向、速度曲线、停顿和抖动，在已完成的自有场景中反求轨迹。
5. 渲染首帧、中间帧、尾帧与 MP4，对照参考后再迭代轨迹；用户本人手动运镜只能作为最后兜底。

单目视频不能唯一还原真实三维路径。存在多解时，记录假设并保留可编辑曲线，不得宣称“物理轨迹完全一致”。

## 7. 后台执行

规格准备好后运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<skill>\scripts\run-blender-whitebox.ps1" `
  -Spec "<项目>\02_输入规格\场景与运镜规格.json" `
  -ProjectDir "<项目>" `
  -Mode all
```

正式动画渲染前先用 `-Mode render-stills` 通过静态构图、人物姿势和穿插检查。任何 Python traceback、缺失构建报告或缺失 `.blend` 都视为失败，即使 Blender 进程返回 0。

## 8. 最终生图提示词

用户要求逐镜生图提示词时，配合 `$yxw-visual-production`：每个剧情镜头输出一条完整中文提示词，存入 `07_生图提示词`。明确分工：

- 白膜截图：只锁机位、构图、人物站位、遮挡、空间高差。
- 人物三视图：只锁脸、体型、发型、妆发和服装。
- 场景参考图：只锁空间拓扑、材质与光色。
- 道具图：只锁道具形制与质感。
- 镜头文字：锁定单帧动作峰值、表情、视线和画面信息。

生图提示词是静帧，不写 BGM、音色、连续台词、转场或不可见的运镜过程；未提供的资产写 `@[对象_待绑定]`，不得臆造。

## 质量硬门

每次交付前完整读取并执行 `references/qa-checklist.md`。至少确认：

- 场景空间关系和高低差可读；
- 姿态和接触闭合，无 T Pose、悬浮或穿插；
- 五个基础机位与所有剧情机位均存在；
- 运动轨迹、注视轨迹和关键帧可编辑；
- MP4 可解码，时长、帧率、起中尾构图正确；
- 项目所有文件只在本次新建的分类目录内。
