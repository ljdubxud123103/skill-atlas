# 人物角色资产提示词｜单文件交接版

本文件同时是可独立安装的 `SKILL.md` 和项目交接文档。运行规则已内嵌，不依赖 `references/`。

## 一、适用边界

仅用于人类人物角色资产：脸基准、身材比例、妆发、服装、正侧背三视图、全身角色板、多套造型、状态变化和批量人物提示词。

不得用于场景、建筑、怪物、生物、道具、武器、打斗镜头或视频提示词。用户只要求分析、审核、修改或提示词时，不得擅自生成图片。

3. 剧本或项目事实。
4. 当前任务指定的参考图职能。
5. 审美库中按题材提炼的抽象规律。

推断、候选和跨项目偏好不得冒充已锁定事实。修改时保留此前已确认且未被本轮推翻的要求。

## 三、核心执行流程

1. 明确资产用途、题材、性别、年龄、身份、性格、脸部区分轴、体态、服装状态、排版和目标模型。
2. 信息不足但不改变人物定位时合理补全；会改变人物身份、时代、服装数量或核心风格时再询问。
3. 建立“人物视觉区分卡”。
4. 标注每份参考的职能、允许迁移项和禁止复制项。
5. 多套或批量方向未锁定时，先给“造型方案概览”；已锁定或用户要最终稿时直接写完整提示词。
6. 按固定 17 段结构交付。
7. 执行妆容、比例、服装闭合、参考不变量和同一性自检。

## 四、人物视觉区分卡

写提示词前先在内部确定：

| 维度 | 必须明确 |
|---|---|
| 身份核心 | 权力位置、处境、行为习惯、情感或危险核心 |
| 脸部结构 | 脸型、面中、颧骨、下颌、眉骨、眼窝、眼睑、眼形、鼻唇 |
| 妆容焦点 | 眼线区段／粗细／颜色／质感，眼影、下眼、眉、腮红和唇 |
| 头发 | 冷暖、发量、颅顶、前侧背结构、柔硬与整齐度 |
| 身材比例 | 头身、上下身分割、肩腰胯、四肢长度和力量类型 |
| 服装轮廓 | 长短、松紧、肩腰下摆重心、如何修正比例 |
| 结构与层次 | 单品件数、内外层、领肩袖腰胯、前侧背开合 |
| 材质与配色 | 主辅材、重量差、光泽差、主色／辅色／点睛色 |
| 记忆点 | 一至两个由结构或材质支撑的识别点 |
| 耦合关系 | 同向强化、软硬对冲、比例修正、身份外壳与性格泄露之一 |

批量人物不得只换发色、瞳色和衣服颜色；至少在脸型、眉骨／眼窝、眼睑、眼形、眼线、眉形、发型、比例和服装轮廓中形成四项实质差异。

## 五、脸—妆—发—服装联动

人物不是四套独立“好看元素”的拼盘。先选一种主关系：

- **同向强化**：骨相、妆发与服装共同放大权力、压迫、纯真、清冷等主轴。
- **软硬对冲**：硬服装配圆感脸妆／柔发，或柔软垂坠服装配锐骨相／清晰眼线；必须有主次。
- **比例修正**：先用短款、腰线、肩线、裙裤长度、鞋型和发量解决全身比例，再用妆容建立视线焦点。
- **身份外壳与性格泄露**：职业或阶层由完整服装成立，真实性格从眼尾、眉形、发束、材质磨损或一个饰件泄露。

性格词至少在两个可见结构中兑现，不能只写“冷、狠、甜、桀骜、妩媚”。

### 5.1 用户认可的四类可迁移模式

这些是拆解逻辑，不是可复制套装：

| 方向 | 服装／头发逻辑 | 脸与妆逻辑 |
|---|---|---|
| 甜酷娇俏、略带锐气 | 短轮廓或高腰优化比例；学院结构作硬骨架；蝴蝶结只作一个受控少女细节；大波浪缓冲硬线 | 圆感杏眼、饱满面中、眼下淡红晕、偏红唇；眼线末端或眉峰保留转折 |
| 清冷疏离的叛逆贵公子 | 灯芯绒／细呢柔化正装；大地色；多层细银饰作局部叛逆信号；蓬松乱发破坏过度端正 | 清瘦锋利轮廓、冷灰蓝瞳、淡唇；男性冷灰／灰褐可见眼线与眼窝晕染不可省略 |
| 阴郁沉稳、强压迫 | 长风衣或纵向叠穿；全黑靠呢料、皮革、针织等粗糙度与光泽差分层；银灰发作记忆点 | 暖深棕瞳、眼尾下压或平推、重眉骨和强骨骼；眼线强调内外边界但保留眼白与虹膜可读性 |
| 清冷妩媚、成熟克制 | 斜肩／不对称缠绕与垂坠面料；结构化露肤；盘发碎发；裸调或低饱和配色 | 狭长凤眼、偏锐五官、通透肤色、低饱和淡唇；女性仍是完整全妆，只降低边界和饱和度 |

蝴蝶结、银饰、露肤和全黑都不是默认必需或禁用项；数量、尺度、位置和材质必须服务人物与比例。

## 六、脸部、眼睑与妆容系统

### 6.1 共同设计顺序

1. 眉骨深度与走向。
2. 眼窝深度及内外差异。
3. 上睑覆盖量、睑板露出量和褶形。
4. 眉眼间距。
5. 眼裂长度、开度、眼头和眼尾方向。
6. 性格与注视方式。
7. 眼线区段、粗细路径、颜色和质感。
8. 内眼线、眼影、下眼／卧蚕、睫毛和眉形。

不得先套流行眼线，再反向编造骨相理由。

### 6.2 眼线完整语法

每条眼线至少写清：

- **区段**：上／下睑、眼头／中段／眼尾、眼裂比例、是否全包。
- **粗细**：均匀、由细到粗、细—粗—细、两端化没或只填睫毛根。
- **颜色**：冷黑、暖黑、深棕、灰褐、冷调红等，写清冷暖与明度。
- **质感**：哑光实色、微雾、柔雾、边缘晕开、干爽不反光。
- **方向**：平推、上挑、下压、外拉、收尖，以及毫米或眼裂比例长度。

### 6.3 男性眼妆硬门禁

男性必须有成图可识别的眼妆。`【妆】`第一项必须是眼线，随后完整写：主眼线、内眼线、上眼皮晕染、下眼／卧蚕、上下睫毛和眉形。可补克制的鼻影、高光、腮色和唇色。

不得用“素颜、无妆、只提气色、自然眼部、无妆感”代替。清冷、阴郁、军装、正装或贵公子方向同样不能取消眼妆。

### 6.4 女性完整全妆硬门禁

女性 `【妆】`仍以眼线开头，且必须覆盖：

1. 眼线与内眼线。
2. 上下眼影与过渡边界。
3. 卧蚕或下眼提亮。
4. 上下睫毛。
5. 眉形与眉色。
6. 底妆、遮瑕和定妆。
7. 面部修容、鼻影与下颌收束。
8. 腮红。
9. 高光。
10. 唇线、唇色、唇峰和质感。

“清透淡妆、自然妆面、精致全妆”只能作总括，不能代替分项。

### 6.5 眼睑映射

| 结构 | 眼线策略 | 避免 |
|---|---|---|
| 极深眼窝／覆盖量大 | 全包、内侧压深、外段加粗或下睑局部；保持可见区 | 大面积压黑导致眼睛消失 |
| 中深／窄外双 | 极细全长、细粗细、短挑、轻下压或上下局部 | 所有人统一黑色上挑线 |
| 浅深／平行褶 | 内眼线、极细线、短线或微雾线 | 用烟熏伪造深眼窝 |
| 平眉骨／单眼皮倾向 | 内眼线更实、上睑短而明确、卧蚕清楚 | 只写“清淡”导致无结构 |

多角色批次中主眼线组合不得重复；至少在区段、粗细、颜色、质感四项形成不同组合。

## 七、体态与比例

- 用可检查锚点描述，不只写“九头身、腿长”。
- 明确头身比、头顶到胯线与胯线到脚底关系、胯／肚脐／膝位置、肩腰胯、颈手脚长度和力量类型。
- 比例服从年龄、身份和项目设定；九头身不是所有人物的硬编码。
- 脸部特写与全身视图的年龄、体脂、颈肩结构和性别表达保持一致。

## 八、服装结构与材质

### 8.1 设计顺序

按以下顺序写 `【衣】`，后一步不得推翻前一步：

1. 剧情、身份和状态。
2. 轮廓与比例修正。
3. 完整单品清单：主体、内搭、外套、下装、鞋履和必要饰件。
4. 结构地图：领、肩、袖、胸省／公主线、腰、胯、开衩、下摆和前侧背开合。
5. 材质分区。
6. 主色、辅色和点睛色层级。
7. 一个主装饰母题和一个辅助母题；核心记忆点控制在一至两个。
8. 完好、湿身、战损、加冕、居家等状态连续性。

### 8.2 材质语法

每种主材质至少回答：

1. 厚薄／重量。
2. 垂坠、回弹或挺括程度。
3. 粗糙度、绒面、颗粒、透明度或光泽。
4. 宽柔高光、窄边高光、散射、透光或暗部纹理等受光方式。

胸省、公主线、骨条、斜裁、抽褶、褶裥、滚边、里衬、暗扣、排扣、拉链、系带或绑带必须连接具体裁片。不得只写“高级面料、华丽剪裁、精致刺绣”。

### 8.3 饰件与固定

- 配饰必须有真实接触和固定点：耳垂、锁骨、布面、肩部、腰线或扣点。
- 多层银饰要分主次、长度和落位，避免穿模；宝石颜色通常控制在一至两种。
- 装饰沿裁片、包边、接缝或真实固定点运行，随三视图转向后保留厚度和背面结构。

### 8.4 三视图闭合门禁

- 正侧背保持服装件数、衣长断点、领肩袖、腰线、裙裤轮廓、装饰数量与落位一致。
- 侧面解释厚度、层叠、胸腰胯转折、开衩和鞋跟；背面解释后领、肩背接缝、腰部收束、开合、后摆和发型背面。
- 拉链、排扣、系带、披挂、链条、刺绣、包边和褶裥的起止点相互对应。
- 衣料遵守重力、人体体积和活动空间，无穿模、悬浮、无支点披挂或裙摆陷地。
- 深色服装暗部可读；浅色服装不过曝；不同材质不能统一成塑料高光。

## 九、参考图、选型与修改

### 9.1 参考职能

逐份标注为：身份基准、脸妆参考、身材比例、服装结构、材质／渲染、排版参考或负向参考。写明允许读取与不得继承的内容；禁止用“综合所有参考”让模型猜测。

### 9.2 多套造型概览

当造型数量、剧情节点或批量区分轴未锁定时，先给表格：角色／状态、造型数量、轮廓与气质方向、脸妆区分、核心材质或记忆点。确认后再写完整提示词。

用户已锁定方向或明确要最终提示词时，不强制增加确认轮次。

### 9.3 单变量选型

A/B/C 选型先锁定人物身份与脸、妆容门禁、比例、视图、姿态、尺度、背景、灯光、媒介和核心结构，再只改变一个主要维度，例如轮廓、材质、配色、领袖、装饰母题、发型秩序或指定脸妆方向。

### 9.4 选中后锁定

把选中版本的可观察结构写回最终提示词：身份年龄、脸与眼睑、瞳色、妆容、发型、比例、服装件数与开合、材质、配色、鞋饰、状态、排版和渲染。“选择 B 版”本身不是锁定描述。

### 9.5 修改句式

> 只修改 X；保持 Y、Z、A、B 不变。

每轮尽量只解决一个问题。更换服装不改脸、年龄、眼妆、比例、肤色、排版和渲染；调整眼妆不改眼睑与身份，除非用户明确联动修改。

## 十、排版与渲染

- 默认：左侧脸部特写约占宽度五分之二；右侧为正面／侧面／背面并排三视图。
- 特写必须看清眼睑、睫毛根、眼线边界、虹膜和肤质；全身必须从头顶到脚底完整入镜。
- 正侧背等高，头顶、胯线、膝盖和脚底分别对齐；衣长断点一致。
- 三视图保持中立、平视、弱透视或正交感，不用低角度、俯拍或荷兰角代替人物气质。
- 只有材质或开合关键时才增加局部细节窗，用于面料、接缝、扣合或饰件固定。
- 白底资产图可以使用，保持明亮、干净、暗部可读；不得把来源手册中的“禁止白底”当全局规则。
- 渲染器、C4D／Octane／PBR 等服从当前项目；工具名不是不可变审美。
