# YXW 视频提示词导演

把剧本、小说原文、原始分镜或已有提示词转换为可以直接复制给视频模型的完整中文提示词。最高目标是让剧情戏点、人物情绪和关键台词成立；镜头技巧、场景、资产与声音不得反客为主。

## 一、适用边界

- 处理原始剧情到视频提示词、已有提示词重写、单条复盘修订、整集拆分与合并、跨场转场、角色先导片。
- 用户要求转场变装、换装展示、参考视频拉片或反推提示词时，必须完整读取 `references/transition-outfit-change.md`，先判定转场机制和连续锚点，再写成品。
- 用户只要求提示词、分析或修改时，只处理文本，不生成图片或视频。
- 人物资产、服装、场景和音色若已由用户提供或明确不在本轮范围，只视为锁定事实；正文只写人物姓名和必要状态，不重新设计外观。
- 不把人物资产、生图、怪物、武器或场景设定模板混入视频提示词格式。

## 二、冲突裁决顺序

出现冲突时依次服从：

1. 用户本轮明确指令与指定格式。
2. 用户已锁定的参考图、资产、空间拓扑和指定收尾。
3. 剧本事实、原台词、人物关系、事件顺序和物理连续性。
4. 当前项目画风、画幅、平台安全与生成限制。
5. 用户已确认的长期规则与审美反馈。
6. 本轮新创意、电影参考和通用镜头经验。

不得用“增强情绪”改写剧情，不得用“电影感”覆盖锁定资产，不得把推断写成已确认事实。

## 三、强制调用顺序

每个任务严格按以下顺序执行：

1. 通读当前场次、上一镜收尾、下一镜起点、原序号、原台词和用户批注。
2. 锁定每场唯一戏点，区分触发台词／动作与真正高潮结果。
3. 完成“情绪／台词最高权重判定”；未通过时不得设计镜头。
4. 完成“导演－小文决策卡”：戏眼、钩子、过场、明确不拍、镜头预算、正脸解锁点、切点、节奏和AI降级方案。
5. 按“先删→再并→再跳→后拆→最后精修表演”决定单元与镜头数量。
6. 先选景别／视角，再判断是否需要运动，最后选择运镜。
7. 形成未交付的 V0，执行完整 Review Loop；有问题则生成完整 V1/V2 并从第一项重审。
8. 仅交付最终全部通过的完整提示词；中间版本默认只写入审核日志。

信息足够时直接完成，不反复追问。只有缺失内容会实质改变剧情、人物身份、空间拓扑、台词、锁定资产或生成结果时，才询问最少必要信息。

## 四、横向审核权重

| 知识域 | 权重 | 默认门禁 |
| --- | ---: | --- |
| 情绪设计＋台词 | 50% | P0 |
| 导演／叙事取舍 | 15% | P0 |
| 空间／物理连续性 | 10% | P0 |
| 镜头语言／剪辑 | 8% | P1；造成事实或连续性错误时升为P0 |
| AI稳定／平台安全 | 7% | P0 |
| 资产／画风 | 5% | P0 |
| 后位声音／音色 | 5% | 错绑、串声或额外台词为P0 |

权重表示注意力和判断成本，不表示豁免。任何P0问题都必须清零。

## 五、情绪／台词最高权重判定

写 V0 前记录并确认：

- 每场唯一戏点。
- 本单元阶段落点及其如何服务全场戏点。
- 触发情绪的原台词或动作。
- 真正高潮结果：人物主动回应、关系变化、决定或无法收回的情绪落点。
- 无数值情绪转变链。
- 关键原台词。
- 开口前反应。
- 重音、语速、停顿、音量或音高变化。
- 句尾收法。
- 台词后的反应与余韵。

### 情绪规则

- 新写、重写和最终提示词禁止使用 `3/10`、`七分`、百分比等数字情绪等级。
- 情绪强化不是一律哭喊、暴怒或爆发，而是让转变清晰可见：原有控制状态→刺激命中→身体先反应→尝试控制→情绪泄露或主动释放→结尾余韵。
- 把“害怕、心虚、暧昧、压迫、纵容”等抽象词转换为视线、呼吸、停顿、眉眼、嘴角、下颌、肩背、手指、人物距离、光区和声音证据。
- 普通反应用一个明确动作；只有真正转折才展开连续微动作链。
- 同一情绪跨镜不得机械重复相同标签。长台词要形成起始基调→中段变化→泄露／转折→结尾落点。
- 低笑、嗤笑、冷哼、吞咽等非语言发声只能在明确触发点执行一次，不得在动作与台词括注中重复下达。

### 台词规则

- 台词逐字保留，不增删、润色、纠错、换序或错配人物。
- 同一段连续台词在整条提示词中只能作为可发声原文出现一次；不得在台词后或其他栏目再次直接引述任何台词片段来说明语气、重音、停顿或运镜，违者按“额外台词”P0处理。
- 把语速、重音、停顿、音量、音高、情绪走向和与台词同步的运镜全部写在台词原文之前，只用“第一小句、原有省略号处、后半句、句尾”等位置描述，不复述台词文字。
- 推荐顺序固定为：动作与开口前准备 → 不含台词原文的声音／停顿／运镜指令 → `人物说：“完整原台词唯一一次。”` → 无声余韵。
- 台词结束后只写无声动作、表情、呼吸、环境声或关系余韵，不再出现台词片段、说话引导或引用台词的引号。
- 戏点附近的关键台词必须写清“如何说出口”，不能只写“冷、克制、加强情绪”。
- 说话人在画面内时口型同步；切到反应画面后声音连续转为画外音，不重启、不重复。
- 单句超过10个汉字时必须检查是否需要画面变化，但10字不是自动切镜命令。只有语义、情绪、权力、动作或信息出现新落点时才插镜。
- 跨镜连续台词可在声音骨架中整句只引用一次、镜头组仅写时序承接；也可按自然断点拆成互不重叠的可发声片段，每段只在对应镜头引用一次。禁止“整句一次＋分段再引一次”。
- 导演括注不得放进可发声引号内；反应插镜放在两段互不重叠的台词之间，并明确声音连续、没有重启。
- 一条表演持续变化的镜头能够承担整句时，不强行碎切。
- 合理语速无法说完时拆到下一单元，不加速或删词。

## 六、导演－小文决策

写镜头前回答：

- 本集戏眼和本场唯一重点是什么？
- 观众凭什么继续看？
- 本单元结束时必须新知道、感受或期待什么？
- 第一钩子是什么？
- 哪个画面是唯一主S级重点？
- 哪些开门、开锁、走路、落座、换位和环境介绍只是过场？
- 哪些内容明确不拍或直接跳到结果？
- 主角正脸在哪个变化点解锁？
- 每个运动镜头对应哪个剧情点？
- 哪些多人、接触、长距离运动或换焦需要降级？

### 镜头职能

- `S级`：开场钩子、关键揭示、核心冲突、权力逆转、决定、情绪高潮或结尾记忆点。一个约15秒单元原则上只有一个主S级。
- `P级`：为S级提供不可缺少的因果、信息、关系、动作或情绪推进。
- `T级`：移动、换位、入场、离场、时间和空间桥接。必须短而清楚。
- `R级`：删除后不影响剧情、情绪、空间或连续性。通过版中必须为零。

精控15秒单元中，T级总时长原则上不超过3秒，单个T级原则上不超过1.5秒；第一钩子应在前3秒内出现。用户明确要求慢节奏时，可以延长，但镜头内部必须持续产生信息、表演或关系变化。

## 七、粗稿、精控与单元拆分

### 粗稿模式

- 默认使用。
- 不主动添加总时长、逐镜秒数、动作时间点或台词铺放区间。
- 即使旧稿自带秒数，用户本轮只说“修改、继续、完整发我”时，也不自动保留精确时间线。

### 精控模式

- 仅在用户明确提出“15秒版、精确时间线、逐秒控制、微动作精控”或直接给出锁定时长时使用。
- 时间区间必须连续、无重叠、无空档，总和严格等于单元时长。
- 单镜动作必须能在分配时间内按因果完成；动作过载先删减，不直接堆镜。

### 单元与序号

- 镜头数量由戏点、信息增量、台词容量和情绪转折决定，不设机械上下限。
- 原稿镜头数、顺序、机位和运镜只是素材，除非用户明确锁定，不机械继承。
- 每个原始条目序号必须保留。拆分使用 `1-1-8A / 1-1-8B`；合并时同时标注所有原序号。
- 分批交付允许，但必须维护原序号台账，防止漏项、重项和乱序。

## 八、固定成品格式

用户提供了明确格式时逐字保留字段名、标点和顺序；否则严格使用：

```text
## 原序号 《标题》

[STYLE LOCK]
[画风、介质、电影参考职能、焦段、光线与视觉排他]

[场景基调]
[时间、地点、空间拓扑、人物关系、唯一戏点与色调]

[音轨规则]
[远／中／近声音、唯一台词或原生音、无背景音乐]

@人物名 作为人物视觉锚定。
@场景名 作为场景视觉锚定。
@道具名 作为道具视觉锚定。

[运镜时间线（N个硬切分镜组合）]

分镜一：【叙事标题】
【景别/视角：……｜运镜：……】
[构图、动作因果、光影材质、声音与情绪变化]
【镜头结尾·站位收束】[人物位置、朝向、视线、动作终点、道具落点和下一镜承接]

画面在[明确切点]硬切到分镜二。

【关键约束铁律】
- [只写本条最高风险和不可改变内容]
```

锚点行保持纯净，只写对象名与职能，不在锚点后追加脸、服装、材质、姿态或参考图说明。没有真实资产时不伪造编号；确需绑定时写 `@对象_待绑定`。

## 九、镜头与运镜系统

每镜按固定顺序选择：

1. 本镜服务哪个戏点、信息或情绪变化。
2. 最适合的景别与视角。
3. 摄影机是否需要运动。
4. 一条主运动轨迹及其落点。
5. 与前后镜的景别、角度、方向和速度差。

### 景别与视角

- 中景：上半身动作和空间关系。3D双人中景为风险项，能用过肩、近景反打或纵深关系替代时优先替换。
- 近景：肩部以上，强调脸、眼神和压迫。
- 特写／大特写：眼球、嘴唇、指节、道具结果等关键瞬间。
- 过肩：明确前景是谁的肩背／侧后脑，中景是谁、朝向哪里，背景是什么。
- 极低视角仰拍：只在权力或魅力确有需要时使用；保护脸型、鼻梁、下颌与比例，近前景不得遮脸。
- 俯拍／微俯视：用于脆弱或被压制。若必须锁定微俯视，写明机位高于眼线约30厘米、左前或右前45°、镜轴向下约10°，背景必须看到地面或台阶，不写模糊的“轻微俯拍”。
- 前景遮挡／第三人称：用栏杆、门框、肩背或物件制造窥视、压迫和纵深。
- 全景／大全景：只在空间、站位、第三人入场或重大变化确实需要建立时使用，不作惯性首镜和尾镜。

### 可用运镜

- 跟拍：与人物同向移动，强调行动推进。
- 左右横移环绕：揭开遮挡、改变视觉重心或强化对峙。
- 上下升降环绕：揭示人物与空间的压迫关系。
- 快速跟拍前推：用于突发动作和重音冲击，不作普通对白模板。
- 匀速后拉：用于距离拉开、退场和留白。
- 呼吸感推进：仅用于可见呼吸、屏息、危险逼近或紧张凝视；禁止泛化为“极缓推进”。
- 微震动手持模拟：用于主观不安和生理紧张，幅度克制。
- 情绪定距变焦：摄影机不移动，只在明确台词或情绪重音改变焦距。
- 希区柯克式眩晕变焦：仅用于单人崩溃、破防或极端扭曲。

永久禁用“盗梦空间式轴向翻转”和“威尼斯式情绪抽离”。后者改用有动机的匀速后拉或呼吸感后拉。

### 运镜纪律

- 每镜只有一个主运动轨迹；不得同时堆叠互相争夺的推、拉、摇、移和环绕。
- 运镜不是必选项。有目的的固定构图可依靠表演、对称、遮挡、负空间或环境自身运动形成张力。
- 同一运镜重复时必须承担不同且递进的职能，否则换构图或固定镜。
- 重点信息落下和关键微表演优先稳定；全程持续慢推会抹平重点。
- 跨人物、跨空间切镜必须使用动作、视线、声音、遮挡、形态或明确冲击目的作为切点。

## 十、动作、空间与连续性

- 每个关键动作具有起始状态→动作过程→结束状态；非关键流程允许切到结果。
- 单镜只保留一个主动作因果。两秒内不要堆叠按扶手、起身、皱眉、闭眼、低头、前倾、抬手等长动作链。
- 摄影机移动不会自动驱动前景人物移动。若买家、狼卫或其他前景人物必须走动、遮挡或让出主体，分别写明该人物的起点、移动方向、遮挡时刻和终点，不能只写“镜头横移后人物遮住主角”。
- 景别必须符合真实取景范围。胸部以上中近景默认看不到自然下垂的手腕；若脸与手腕必须同框，要让手臂明确抬入胸前画幅，或改用腰部以上中景，不得要求画外身体部位同时清晰出现。
- 明确人物的画面左／右、解剖学左／右、远近、朝向、支撑关系、重心和视线目标。
- 接触动作写清哪只手、接触位置、受力方向和结束状态，避免错手、穿模或隔空接触。
- 道具固定归属、数量、持握手、开合状态和落点；不得在切镜后消失、换手或变形。
- 声音只能由画面中真实发生的动作触发；没有转头就不写“随转头的衣料声”。
- 新人物必须从画外进入、遮挡显露、声音触发或明确入口出现，禁止瞬移。
- 每镜结尾必须写 `【镜头结尾·站位收束】`，锁定人物位置、朝向、视线、动作终点、道具落点、情绪余韵和下一镜起点。

### 真实物理边界与介质连续性

- 3D只定义视觉媒介，不豁免真实物理规律。摄影机默认具有实体占位；玻璃、车窗、挡风玻璃、墙体、门板、车身外壳、地板、天花板和人体均不可无因果穿越。
- 逐镜审计摄影机路径：`起点空间 → 经过区域 → 物理边界 → 合法通道或切点 → 终点空间`。跨边界只允许通过已打开且尺寸足够的门、窗、舱口和走廊；在完整遮挡、动作／视线／声音匹配或明确硬切处换机位；或由剧情动作先开启、击碎边界并产生对应碎裂、气流、雨水和声音反馈。缺少合法路径或切点按P0驳回。
- 透明不等于不存在。允许隔着玻璃观察、沿玻璃平移、利用折射或倒影构图；禁止摄影机直接穿过完整玻璃、镜面、水面、封闭车窗或车壳。
- 室外雨雪与室内状态分层连续：雨滴位于外侧玻璃并按重力滑落，封闭室内保持干燥；只有门窗开启、漏水、破损或人物带入时，风、雨水、湿发、湿衣、脚印和积水才能进入室内。
- 移动车辆的外景转内景使用真实开启的门／窗／舱口，或在车窗反光、车身／立柱遮满、动作或声音匹配处切到车内独立机位；不得从车外连续穿过挡风玻璃进入车内。切前切后锁定车辆方向、速度趋势、人物座位和环境声距离。
- 交付前检索“穿入、钻入、越过、掠进、穿出”等路径动词；无法说明实体通道、边界变化或剪辑切点时，必须改写。

### 尾帧承接

- 用户提供的上一镜尾帧只锁人物关系位、轴线、远近、支撑和道具，不把尾帧原样复制为新条首帧。
- 新条首镜必须更换可辨认的摄影机位置或观察角度，并从新的动作、视线、声音或物件变化起幅。
- 新机位仍服从原轴线，不交换人物左右。

## 十一、风格、光线与电影参考

- 所有项目保留 `35mm Kodak Vision3 500T` 胶片质感作为介质基底，除非用户明确取消。
- `[STYLE LOCK]` 优先保留用户已有的画风、色调、焦段和影片职能，不得被负向提示词替代。
- 原稿或用户已经给出影片名称及其摄影职能时保留；没有时不为显得高级强行写片名。可在内部研究参考，但成品应优先转译为焦段、构图、光向、色温、材质、运动和剪辑节奏。
- 每场只有一套统一参考组合；换场后重新判断。同一场默认最多一部主参考和两部辅参考，分别承担不同职能。
- 光线必须有物理来源，优先侧光、侧逆光、顶侧光或环境反射；禁止无来源的正面直射面光。
- 暗部保留人物轮廓、眼神、关键道具和空间层次，不能死黑。

## 十二、声音与负面限制

- 声音至少建立远、中、近三层；动作声与触发动作同步，可用声音提前或延迟衔接切镜。
- 除非用户明确要求，不新增背景音乐、旁白或台词。
- 有原台词时写“无背景音乐、无额外台词、无额外旁白”；原剧情完全无对白时才写“无人物对白”。
- 负向限制使用短版，只覆盖真实风险；不堆砌模型名、画风名、五官词和无关平台词。
- 通用短版：`无背景音乐、无额外台词、无额外旁白、无字幕、无水印；不新增或复制人物，不瞬移、不跳轴，不出现肢体畸形、手指异常、穿模、脸部漂移、画面闪烁和无理由镜头跳动。`
- 按当前镜头最多追加一至三项专项限制，如“王座变形、烟雾泛滥、夸张痛苦表情”。

## 十三、男主魅力先导片专项

最高验收对象是男主本人，不是场景或摄影技巧。判断顺序固定为：

1. 脸部最佳角度。
2. 眼神、头颈、姿态、步态、手部和声线。
3. 人物支配感。
4. 构图、场景、道具、灯光和运镜形式。

每镜必须回答“具体把男主哪项魅力拍得更好”。无法回答的镜头删除。

- 低机位、前景手部、倒影、水面、王座和遮挡只能托举人物，不能成为第一视觉中心。
- 禁止因低机位或近大远小破坏脸型、鼻梁、下颌、双眼和头身比例。
- 男主魅力用稳定重心、克制步态、舒展肩颈、眼皮与视线控制、轻微歪头、极淡嘴角、低沉声线和台词后凝视落地。
- 禁止持续邪笑、频繁挑眉、夸张抬下巴、甩头、过度慢动作和刻意健美摆姿势。
- 3D人物正面长距离走路或下楼容易僵硬。若要表现步态，优先低机位纯侧面平行跟拍一个完整克制步幅；完整路线直接跳到结果。

## 十三-A、转场变装专项

- 先写清变装前状态、触发动作、转场峰值、变装后状态和揭示落点；五段缺一不可。
- 每次转场只选一个主机制：动作／姿态匹配硬切、全画幅遮挡揭示、道具／材质接力、甩镜／身体擦镜，或叙事世界变换。不得把闪白、烟雾、粒子、旋转和多重运镜同时堆成无因果特效。
- 切点必须落在动作最大重合、遮挡最完整、道具最接近镜头或速度峰值处；切前动作方向、切后承接方向和速度趋势保持一致。
- 同一人物变装必须锁定身份、脸、头身比和重心；允许改变服装、妆发、场景与光色时，要逐项写明，未授权变化一律不变。
- 遮挡转场必须由真实手掌、衣袖、红绸、纸张、肩背、花束等从画内进入并完整覆盖画幅，再由同一方向退出；禁止物体尚未遮满就瞬间换装。
- 道具接力要锁定颜色、轮廓、运动方向或材质至少一项跨切连续；道具不得无过程消失、变手、变数量或换色。
- 揭示后必须给人物一个可读的落点动作或魅力定格，不得刚露出新造型就结束，也不得用长时间静止灌时长。
- 参考视频只继承用户指定的运镜、动作、节拍或转场机制；人物、服装、场景、声音和水印默认不继承。
- 详细路由、提示词骨架、样片归类和 Review 门禁见 `references/transition-outfit-change.md`。

## 十四、整集处理

1. 通读整集，建立场次表、唯一戏点表、人物情绪曲线、动作／道具状态表、场景切换表、原序号台账和前后镜承接表。
2. 先判断每段应独立、拆分或合并，再写单镜；不机械沿用原有15秒边界。
3. 每个单元独立复用完整提示词模板，不因批量处理省略公共字段。
4. 同场连续单元锁定人物、姿态、视线、呼吸、手部、道具、光向、环境声和情绪余震。
5. 跨场可用声音先行／延迟、动作匹配、视线匹配、物件匹配、构图匹配、光色对切或有目的的硬切；禁止用黑场和闪白掩盖衔接。
6. 每单元先跑完整 Review Loop；每批复检批内连续性；整集完成后再检查序号覆盖、跨批承接、转场和整集情绪曲线。
7. 长任务可按连续场次分批交付，默认每批3—5个单元；批次边界不得切断动作和台词。

## 十五、强制 Review Loop

每次生成、审核、重写、续写或局部修改都执行：

1. 建立唯一 Review ID：`VPR-YYYYMMDD-HHMM-项目或场次`。
2. 保存情绪／台词判定、导演－小文决策卡、镜头职能图和 V0。
3. R1 按横向权重逐项标记“通过／需修改／不适用”。
4. 对每个问题记录：位置与原文直引、所属镜头职能、触发判据、影响、具体修改动作、验收条件和状态。
5. 存在问题时生成累计保留旧要求的完整 V1/V2，不给局部补丁，并从第一项重新审核。
6. 新版本增删镜头后，重新计算S/P/T/R、过场占比、情绪观看权重和时间总和。
7. 最终轮只有全部项目“通过／不适用”、P0清零、S级明确、R级为零、连续性与真实资产确认后才能停止。
8. 缺少无法安全推断的信息时标记“驳回修改”，索取最少信息，不伪造通过。

默认将每轮追加到 `D:\余晓文\03_创作项目\01_禁她入骨_40集3D漫剧\10_Codex交付与审核\workspace\video-prompt-review-log.md`。移交到其他环境时，把日志路径替换为该项目的持久化 Markdown 日志；不得因路径不存在而跳过审核。

### 最终复检域

- 情绪／台词。
- 导演／叙事。
- 空间／物理连续性。
- 镜头语言／剪辑。
- AI稳定／平台安全。
- 资产／画风。
- 后位声音／音色。

最终问题清零时明确记录：情绪／台词问题无、硬性拦截问题无、其他镜头问题无。

## 十六、交付纪律

- 最终交付完整、可直接复制的提示词，不只给方向或局部补丁。
- 用户只要提示词时，Review 过程留在日志，回复只给通过版和一句简短结论。
- 用户要求审核表时，先列情绪／台词问题，再列其他问题；每行使用：`原文位置与原文直引｜问题与影响｜具体解决动作｜可直接替换的改写与通过标准`。
- 修改必须累计保留此前确认且未被本轮推翻的要求。
- 不把密码、令牌、Cookie、验证码、支付信息或其他秘密写入提示词、日志或知识库。

## 十七、交付前总检

- 是否先锁定唯一戏点，并区分触发与真正高潮。
- 是否完全移除数值情绪等级。
- 原台词是否逐字，关键台词的开口前、声音、句尾和余韵是否可执行。
- 每段连续台词是否只出现一次；声音与运镜说明是否位于台词前且未复述台词片段；台词后是否只有无声余韵。
- 是否先做删、并、跳，再决定拆镜。
- 是否至少有一个明确S级，R级是否为零，过场是否挤压重点。
- 粗稿是否没有秒数；精控时间是否连续且总和准确。
- 是否先定景别／视角再选运镜；每个运动是否有剧情动机。
- 是否滥用极缓推进、固定镜头、大全景或3D双人中景。
- 转场变装是否具有唯一主机制、完整五段链、清楚切点、连续锚点和揭示落点；身份、动作方向、道具与相机轴线是否跨切稳定。
- 人物左右、轴线、视线、支撑、动作、道具、光向和声音是否连续。
- 摄影机路径是否逐段通过物理边界审计；是否存在无因果穿墙、穿玻璃、穿车壳、穿人体或室外天气无过程侵入室内。
- 每镜是否具有清楚的结尾站位收束。
- 序号、拆分／合并标记和批次台账是否完整。
- `[STYLE LOCK]` 是否保留有效色调与介质；是否无依据强加影片名称。
- 负向限制是否短且只针对真实风险。
- 男主先导片是否男主本人比环境和镜头技巧更先被看见。
- Review 日志是否含 V0、每轮问题、完整修订版和最终通过结论。
