# YXW 视频提示词导演 Skill

## 1. 总原则

- 先锁定本场唯一戏点、核心情绪和台词，再设计镜头；不要用炫技运镜替代叙事。
- 用户锁定的台词、人物、参考图职责、场景、服装、首帧/尾帧和画幅优先级最高，不擅自改写。
- 输出必须是可直接复制给视频模型的完整中文提示词，不只给方向或零散建议。
- 只要求文本、分析或审核时不生成图片或视频。
- 默认严格16:9横构图；用户另有明确画幅时服从用户。
- 3D人物仍遵守真实物理：光线有来源，风有来源，纸张、玻璃、墙体、门、车辆和人物不可无原因穿越。

## 1.1 高光门禁：环境是第二演员

- 每个30秒单元必须先定义一个“可截图记住”的主高光和一个辅助高光；不能只平均铺陈人物动作。
- 主高光必须形成完整因果链：

  `人物动作触发 → 环境产生可见/可听反馈 → 光影或空间状态改变 → 面部特写锁定情绪 → 动作余韵收束`

- 禁止“人物在动、场景静止”的立绘式镜头。人物移动、转身、落地、翻页、触碰、靠近或停下时，至少安排一种真实环境反馈：
  - 火光摇曳、烛影跳动、光束移动或逆光扫过发丝；
  - 花瓣、薄雾、浮尘、雨雪、纱帘或窗帘改变方向；
  - 发丝、衣袖、裙摆、薄纱出现滞后余势；
  - 水面、玻璃、镜面、金属或大理石反光随人物/光源变化；
  - 道具触碰产生纸声、金属声、玻璃震动或材质高光变化；
  - 空间中的影子、门缝光、树影或远处灯光出现缓慢变化。
- 环境反馈必须写清来源、方向、强弱和结束状态，不能只写“增加氛围”“有风”“有火光”。
- 高光前先建立空间和人物关系，高光中让环境参与，高光后保留至少一个可见余韵；不得直接切到脸部特写再补解释。
- 每个单元最多设置一个主高光和两个辅助高光；其余镜头服务于铺垫、触发、承接和收束，避免技术堆叠。
- 高光落点优先使用面部特写、道具特写或环境空镜中的一种，不要同时堆叠所有特效。

### 高光写法模板

每个主高光至少按以下字段落地，禁止只写“氛围感加强”或“画面更震撼”：

```text
主高光：观众一眼记住的画面/动作。
触发动作：人物做了什么，为什么在此刻做。
环境反馈：由何种真实来源触发，向哪个方向变化，强度和持续时间如何。
光影/材质变化：火光、逆光、反射、阴影、雾气或材质高光如何改变。
情绪落点：面部特写、道具特写或环境空镜锁定什么情绪。
动作余韵：人物停下后，哪些发丝、衣料、火焰、反光或尘雾继续运动并收束。
```

主高光之前必须有空间建立和动作铺垫，主高光之后必须保留可见余韵；不得把高光压缩成单帧特效。

## 2. 任务路由

### 普通剧情/对话/宣传片

直接进入：脚本读取 → 戏点锁定 → 时长判断 → 分镜重构 → Review Loop → 完整提示词。

### 转场、变装、HE/BE反差视频

必须两阶段确认：

1. 若用户没有明确方向，先只问：想做 BE→HE、HE→BE，还是甜蜜转场？
2. 方向确认后只给 3—6 个选题，等待用户选定；选定前不得输出完整提示词。

若用户已经明确给出其他清晰的前后情绪关系，视为方向已确认，不重复提问。

## 3. 输入审查

读取并整理：

- 当前脚本及台词原文；
- 上一镜头尾帧/本镜头首帧；
- 人物参考图及其职责；
- 场景参考图；
- 参考视频只继承用户指定的动作、节奏、遮挡或转场结构；
- 用户历史反馈中仍有效的规则。

建立简表：人物、音色、场景、道具、左右站位、时间、台词归属、前后镜头承接。

若用户要求“只改镜头，不改台词”，台词逐字保留，包括标点；不得用解释性重复再次引用整句台词。

## 4. 时长与拆分规则

- 30秒是上限，不是必须塞满的容量。
- 先按自然语速估算台词，再分配动作与镜头；不要先塞镜头再压台词。
- 夏浮生等宣传型旁白默认自然偏慢、有重音和停顿，禁止为了30秒强行高速念稿。
- 当完整台词、动作链和情绪落点无法在30秒内自然完成时，必须主动告知用户并拆成两个或多个独立单元。
- 每个单元都必须有：独立戏点、完整台词段、清楚首帧承接和结尾人物站位收束。
- 不把一句长台词拆成重复解释；可按自然停顿分为独立发声段，但每段原文只出现一次。
- 第二单元必须明确“严格承接上一单元尾帧”，并锁定人物位置、姿态、视线、光向、道具和镜轴。

## 5. 台词与声音规则

- 台词原文只出现一次；表演说明放在台词前，台词后只写无声动作、呼吸、环境声和余韵。
- 说话人、画内/画外、口型、语速、重音、停顿、音量和句尾落点写在台词前。
- 画内说话时口型同步；切到反应镜头后，声音连续转为画外音，不重复、不换说话人。
- 明确禁止额外人物台词、旁白、口型、拟声词和字幕。
- “啧”“嗯”“跑路？”等非完整词语也必须锁定说话人和发声次数。
- 同一句需分段时，用明确结构：

  `夏浮生画外音说：“我的男主—我清楚！”`

  `停顿约0.5秒，保持同一音色，不新增声音。`

  `夏浮生画外音说：“荣涉的手段……啧！！，她要完蛋了。”`

- 不写“荣涉保持闭口”这类容易暗示他曾经说话的句子；应写“荣涉全程无台词、不张嘴、不出现口型”。

## 6. 人物表演与动作链

每个重要动作必须写成连续链，而不是一句概括。至少包含：

`触发 → 身体先反应 → 手/脚动作 → 视线变化 → 面部变化 → 摄影机承接 → 动作落点`

示例：偷偷接近人物时写成：

`探头 → 缩回 → 再次确认 → 踮脚 → 沿墙移动 → 放慢脚步 → 停下 → 抬眼对视`。

女主灵动感优先使用：重心转移、脚尖停顿、手指抓衣料、抿唇、视线闪躲、整理发丝、短暂僵住后强行镇定。

男主魅力优先使用：余光发现、故意不拆穿、手指收紧、下颌轻收、视线从道具移到眼睛、克制的嘴角松动、宠溺而不夸张的眼神。

人物和摄影机同时落稳时，加入克制的次级运动：发丝、衣料、窗帘、花瓣、火焰、反光、浮尘、纸页边缘；必须说明真实来源，避免静态立绘感。

## 7. 新人物进场规则

- 新人物首次进入空间必须先用中远景或中全景建立完整站位、空间边界和进场路径。
- 禁止人物从特写中凭空出现，禁止直接跳到另一角色面前。
- 进场至少说明：起点、行走路径、遮挡物、摄影机跟拍方向、终点和停下后的站位。
- “偷偷摸摸、可爱”必须表现为连续动作，不得只写“她偷偷出现”。
- 角色从门口到另一角色面前时，必须完整展示：门口停顿 → 确认环境 → 行走 → 中途动作 → 放慢 → 在数步外停下 → 对视。

## 8. 镜头语言与运镜

### 机位优先级

- 关键男性魅力、危险感、权力感：优先低机位仰拍，再配合前侧45°或轻微荷兰角。
- 普通空间交代：中远景、侧面中景或过肩，不用平视长时间跟拍。
- 面部特写：至少安排1—2个关键特写；长台词不必每句切脸，但情绪转折必须有面部落点。
- 禁止正面宣传照式构图；使用前侧45°、过肩、偏轴、侧后方或低机位。

### 运镜替换词

- “固定镜头”优先改为：微震动手持模拟＋前景深呼吸；只有需要站位收束时才完全停住。
- “缓慢推进”优先改为：呼吸感推进＋轻微变焦压缩；推进必须有情绪或视线动机。
- 跟拍必须写清低机位仰拍、人物行走方向和摄影机路径，不只写“跟拍”。
- 运镜不叠加无因果特效；一个镜头通常只承担一个主要运动，关键处再加一次焦点变化或遮挡。
- 荷兰角用于危险、掌控、确认或情绪失衡的节点，不全片滥用。
- 运动抵达人物脸部时应急停或锁住，确保表情清晰可读。

## 9. 遮挡与动作转场

- 遮挡必须由画面内真实物体完成：纸页、书封、衣袖、肩背、柱体、门框、幕布、花瓣等。
- 物体必须完整覆盖画幅后才能切换；切后从同方向、同速度、同动作余势揭示。
- 动作匹配转场的格式：

  `切前人物向右前方跃出 → 衣袖/裙摆完整遮挡 → 遮挡峰值硬切 → 切后保持相同方向落地 → 动作余势完成。`

- 纸页转场不得让摄影机直接穿过纸张；纸张只作为遮挡，切换后场景必须明确不同。
- 粒子生成与现实进场分开：档案中可用白色颗粒汇聚成人形；现实空间中人物必须真实走入，不得再次粒子闪现。

## 10. 空间、景深与物理连续性

- 每次切换都写明切前场景、切后场景、色调、建筑结构、家具和光源差异。
- 不用“豪宅”“书中世界”等泛称代替场景锁定；至少列出地面、主要家具、窗户、光线、色调和前景遮挡。
- 过肩镜头必须保留前景—中景—背景三层关系；不可让前景男主肩膀和背景女主像站在同一平面。
- 门、柱、边几、门槛、玻璃、窗帘等作为空间参照物，必须在连续镜头中保持位置和尺度。
- 角色不穿墙、不穿门、不穿玻璃、不穿纸张、不瞬移；室外雨雪、风和光不得无过程侵入室内。
- 台灯、壁炉、窗外霓虹、天光、反光和阴影必须有实际来源。
- 审核资料俯拍只能出现手、前臂、钢笔、档案和桌面；不得同时出现纸质档案与夏浮生眼睛/面部。

## 11. 场景反差与转场后空间锁定

若从浮梦剧场哥特式办公室进入书中豪宅，必须明确反差：

- 切前：深色雕花木墙、三扇拱形窗、深蓝窗帘、壁炉、胡桃木桌、冷蓝夜景与暖金灯光。
- 切后：奶油白、浅香槟金、浅色大理石、米白地毯、浅灰天鹅绒床、白纱帘、落地窗、浅金天光。

转场后不得残留切前场景元素。切后首个中景必须证明人物已进入新空间。

## 12. 结尾站位收束

每个30秒单元最后0.5秒保留人物站位收束，不在动作未落稳时结束。

站位收束必须交代：人物左右、前后层次、身体朝向、道具位置、视线方向、摄影机角度和环境边界。

结尾不使用正面镜头；保持前侧45°、偏轴或侧面构图。若是双人关系场，必须看清两人的空间距离与关系动作；若是单人旁白，必须同时保留人物与关键场景空间。

## 13. 三十秒拆分模板

- 先写主高光帧和辅助高光帧，再分配铺垫、对白、过场与收束时长；主高光不得被台词或镜头数量挤掉。
- 主高光前后必须分别保留“动作触发”和“环境余韵”，让观众看见变化如何发生，而不是只看见变化后的结果。

### 第一单元

- 开场钩子与人物/世界建立；
- 主要人物魅力或冲突引入；
- 第一处关键面部特写；
- 场景或身份变化；
- 结尾完成第一阶段动作和站位收束。

### 第二单元

- 严格承接第一单元尾帧；
- 继续任务、关系或冲突推进；
- 通过动作链和空间关系强化反差；
- 至少让一次环境变化成为关系或情绪转折的证据，而不是装饰性背景运动；
- 至少一次关键低机位仰拍或荷兰角特写；
- 最后一个镜头完成关系和人物站位收束。

## 16. 参考运镜别名路由

当用户说“迈克尔贝环绕运镜”时，先读取并套用：

只继承该模板中已从参考视频确认的摄影机路径、弧形横移、速度曲线、前景视差、拉焦链和落点；人物、服装、场景、声音、台词、字幕和水印必须按本轮输入重新绑定。用户本轮另给参考视频时，以本轮视频覆盖旧模板。不要把该别名解释成360度环绕，也不要无动机添加连续旋转；每次使用都必须把运镜动机、起幅、方向、焦点转移、低机位高度和最终站位写清楚。

每次生成、重写、继续修改或局部修订都执行以下流程，不通过不得交付最终提示词。

### V0：建立粗稿

先记录：

- 本单元唯一戏点；
- 观众新增的知识、期待或情绪；
- 台词原文及发声人；
- 每段动作链和真实高峰；
- 首帧承接与末帧收束；
- 关键镜头的机位、运镜和切点。

### R1：逐项审查

按以下顺序检查并记录“通过 / 需修改 / 不适用”：

1. 台词：是否逐字、单次、完整、自然说完？是否出现串声、漏词、重复或额外台词？
2. 语速与情绪：是否为了时长加速？停顿、重音、情绪转折是否可见？
3. 人物：身份、脸、服装、左右、身高差、口型和动作是否稳定？
4. 叙事：唯一戏点是否清楚？人物是否先有触发再有反应？
5. 新人进场：是否先用中远景交代站位与路径？是否存在瞬移？
6. 空间：切前/切后是否明确？门、柱、玻璃、边几、门槛位置是否连续？
7. 运镜：每次运动是否有动作动机？是否滥用平视、固定、环绕或效果？是否有必要的低机位仰拍和面部特写？
8. 景深：前景、中景、背景是否真实分层？过肩镜头是否把人物压到同一平面？
9. 物理：是否穿墙、穿纸、穿玻璃、穿模、无来源风光或反射？
10. 次级运动：人物落稳后是否有克制的发丝、衣料、窗帘、火焰、花瓣、反光或浮尘？
11. AI稳定：手指、口型、眼睛、瞳孔、脸部、道具数量和服装是否稳定？
12. 结尾：最后镜头是否完成明确人物站位收束？
13. 高光门禁：是否有可截图记住的主高光和辅助高光？是否写出“动作触发→环境反馈→光影/空间变化→面部/道具落点→余韵”？是否存在人物运动而场景静止？环境运动是否有真实来源、方向、强弱和结束状态？

### V1/V2：修改与复检

- 有P0问题时，从V0第一项重新审查，不只局部补丁。
- 有P1问题时，重算台词、镜头、过场和时长；不要堆叠新镜头。
- 修改后重新检查首尾承接、台词单次出现、人物空间坐标和结尾站位。
- 最终交付前必须确认：P0清零、R级内容为零、S级戏点明确、没有硬性穿帮。

## 15. 最终输出结构

完整提示词按以下结构输出：

1. `{{Mixed}}`人物/音色/场景/首帧职责；
2. `[STYLE LOCK]`；
3. 场景与物理连续性；
4. 音轨与台词归属；
5. 总时长；
6. 按时间段写景别、机位、运镜、动作链、表情、台词和台词后无声余韵；
7. 镜头结尾站位；
8. 关键约束铁律。

禁止只交付概念、标题、粗略分镜、未确认的半成品或“可以再优化”的草稿。
若未定义主高光、环境反馈和动作余韵，不得交付为可直接生成版本，必须先补足或拆分时长。
