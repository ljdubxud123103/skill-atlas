# 国内女频 3D AI 精品漫剧分镜

## 版本信息

- 当前版本：`v9.4.0`
- 发布日期：`2026-08-08`
- 维护规则：每次修改本 Skill 的指令、模板、参考规范、脚本或界面元数据都必须更新版本号，并同步更新根目录 `VERSION`、本节、`agents/openai.yaml` 的显示名称和版本化压缩包文件名。
- 版本递增：不兼容的结构或规则调整升主版本；新增兼容能力升次版本；修正措辞、示例、校验或小问题升修订版本。

把中文女频剧本转成可直接进入“资产制作 → 镜头画面生成 → 视频生成 → 角色配音口型 → 剪辑合成”的声音忠实型生产包。以女性观众的情绪体验、3D资产一致性、镜头内叙事和16:9横屏可读性为核心。

最高导演原则：每次都先按“整剧人物欲望与关系终局 → 本集核心情绪与次要情绪 → 本场情绪使命”反推内容轻重，再把大部分镜头时间留给能够证明人物感情、欲望与选择的表演；环境快速交代，过场动作快速带过，绝不按动作数量、剧本行数或出现顺序平均分配镜头。

## 先判断任务类型

- 收到完整剧本或单集剧本：先审校，再输出前期分析包。
- 收到已确认的某集、场次或连续场次：先核对现有资产，再生成分镜。
- 用户明确要求“直接生成提示词”：在完成必要的后台审校、资产核对与表演轨迹计算后，直接输出可复制的镜头提示词块，不先展示分析过程。
- 用户要求“审核、对比、看看怎么改、优化已有提示词”：先核算原稿的秒数、镜头数、特写和运镜分别服务了什么，再给出整集核心/次要情绪、本场情绪使命与重分配方案，最后按正式格式修订。
- 只要求角色、场景或道具：只生成对应资产卡，不擅自扩展为整集分镜。
- 只要求改稿或审稿：按用户要求报告问题或提出有限改编方案；默认只调整非语言画面与动作说明，不生成、删减或改写任何台词、内心音、明确旁白和剧情内语言。
- 已有画风图、角色图、资产表或音频：视为高优先级约束，优先读取并沿用。
- 输入不是剧本格式时：说明本 Skill 以剧本为生产输入，要求用户提供完整剧本、单集剧本或明确场次；不要自行展开小说或网文改编。

## 识别剧本要素

将输入严格归入以下类型：

- 场次头：集数、场号、内/外景、地点、日/夜或具体时段。
- 动作与场面说明：人物行为、空间调度、环境变化和可见剧情事实。
- 表演提示：语气、停顿、表情、动作括注。
- 角色对白：角色在画面内实际开口说出的内容。
- 角色内心音：明确标记的心声、OS 或第一人称主观声音。
- 明确旁白：剧本明确标记为旁白、解说、画外讲述、VO、Narrator 或同义声音字段的成片语言。
- 剧情内媒介：电话、广播、录音、视频播放、短信、文件和屏幕文字。
- 制作备注：导演、镜头、后期或特效说明，不属于成片台词。

## 获取最低必要输入

优先从用户材料中提取，不重复询问。缺失时采用以下默认值，并在输出开头简短声明：

- 语言：普通话中文。
- 画幅：固定16:9横构图。
- 风格：电影感半写实 3D 国漫，精致角色建模，非真人实拍，非 2D 平涂。
- 声音：只允许逐字来自剧本的角色对白、角色内心音、明确旁白和剧情内有声媒介，以及不新增语言信息的环境声和音效；剧本未明确标注时严禁自行新增第三人称解说、上帝视角解说或画外讲述，禁止BGM和配乐。
- 单集时长：按用户剧本与音频决定，不擅自删剧情。
- 生成单元：按剧情和完整音轨确定，生成素材总时长不得超过30.0秒；不添加开头定位大全景，叙事内容最多29.5秒，结尾固定0.5秒完全静止大全景。普通叙事镜头硬性不得超过3.0秒；简单过渡优先0.8–1.2秒，情绪特写优先2.0–3.0秒。30秒单元最多允许两个互不相邻、分别服务不同情绪节拍的3.1–5.0秒核心关系长镜头；内容不足时自然结束，严禁凑满30秒。
- 制作路线：资产锚定 → 分镜画面内容 → 视频生成 → 配音/口型 → 剪辑。

若生成平台、单次视频时长或配音成品时长会实质改变拆镜，先询问一个最关键问题；否则使用默认值继续。

## 源剧本明确旁白最高优先级规则

剧本是声音内容的唯一依据。剧本明确标有旁白、解说、画外讲述、VO、Narrator 或其他同义成片声音时，该内容不是阻断项，必须按剧本标准执行：

- 保留原声音类型、原说话人或声源、原文字、原词序、原标点和原出现顺序，不得删改、润色、缩写、扩写、重新断句、转移归属或重复。
- 不得把明确旁白改成角色对白、角色内心音、字幕、标题卡、剧情内媒介或其他声音；也不得用上述形式替代明确旁白。
- 明确旁白可连续跨越多个视觉切镜，切镜时音色、语速、音量、情绪、混响和音轨均保持连续；不得因单镜3秒上限中断、重启或复述。
- 明确旁白默认是画外声音，不驱动画面内角色口型；只有剧本明确指定可见人物正在说出该内容时，才为该人物配置口型。
- 剧本未明确标注旁白时，严禁模型自行新增第三人称解说、上帝视角解说、画外讲述或总结性声音。
- 动作说明、场面说明、表演提示、心理提示、背景资料和制作备注，若没有明确标记为可听见的旁白，不得被朗读。
- 角色内心音、心声或 OS 仍须明确存在于剧本，标明原角色并逐字逐标点复现；剧本没有时严禁新增。
- 剧本已有电话、广播、监控录音、视频播放等剧情内声音时，注明原声源并逐字不变。

剧本含动作说明、场面说明、心理提示或背景信息时，按以下顺序执行，且不得生成任何原剧本不存在的语言内容：

1. 用角色可见动作、表情、身体反应、空间关系、道具状态或环境变化直接呈现。
2. 心理提示只能转化为表情、呼吸、姿态、动作、视线或空间关系；只有原文明确标注为内心音时才保留声音，且逐字不变。
3. 仅当剧本原文已存在短信、聊天记录、信件、合同、新闻或监控媒介时，按原文呈现，不新增文字。
4. 使用插叙、平行剪辑、主观镜头或无声反应镜头补充可见信息，但不得补写语言。
5. 无法在不修改受保护语言的前提下完成时，列为阻断项；可对非语言画面做不改变因果与关系结果的小幅改编，但不得擅删、改写或生成替代台词。

## 台词零删减与有限视觉改编锁

生成任何分析、分镜或提示词前先读 [script-verbatim-lock.md](references/script-verbatim-lock.md) 与 [female-oriented-adaptation.md](references/female-oriented-adaptation.md)。所有对白、内心音、OS、明确旁白、电话、广播、录音和视频播放语言必须保持原字、原词、原顺序、原标点和原说话人或声源，严禁新增、删除、改写、润色、调序、重复或重新分配。允许小幅压缩、合并或替换重复且不提供新信息的动物、风景、赶路、气氛、群演或等价动作画面；不得改变事件结果、因果、时序、人物身份与动机、线索归属、关系推进、入退场逻辑或道具连续性。男女主初见、对视、触碰、救援、保护、对抗、权力反转、女主主动选择和关系兑现属于受保护关键节点，不得删减，只能强化。任何改编都应最小、可追溯；无法确认是否承担伏笔、象征、空间连续性或情绪递进时一律保留。

## 强制工作流

### 1. 审校剧本

开始设计或审核任何镜头前，必须从场次头到场尾完整阅读本场全部剧本，不得跳读或只看待生成的局部台词。先确认人物关系、戏剧目标、事件顺序、全部台词、关键动作与信息点，以及每名主要角色的情绪起点和终点，再检查：

1. 人名、称谓、性别、人物关系与身份是否一致。
2. 时间线、年龄、怀孕/伤势/换装/交通所需时间是否合理。
3. 场景切换、出入口、人物站位和动作路径是否成立。
4. 同一连续场景前后在场人物名单是否变化；每名减少角色是否有完整退场路径，每名新增角色是否有完整入场路径。
5. 场次头、对白归属、角色内心音、动作/场面说明、表演提示、短信/屏幕文字是否清楚；逐项规划镜头执行方式。
6. 道具归属、损坏、交接、遗失与重新出现是否连续。
7. 女频核心诉求是否清楚：女主目标、阻力、情绪代偿、关系进展、反转回报。

使用 [output-templates.md](references/output-templates.md) 中的“剧本审校报告”。只把会阻断制作的问题标为阻断项。非阻断问题不应迫使用户暂停。

### 2. 建立场级情绪导演图

拆镜前必须读取 [scene-emotional-priority-audit.md](references/scene-emotional-priority-audit.md)。严格按“整剧层 → 本集层 → 本场层”推导：先梳理主要人物欲望、关系弧与后续关键选择；再确定本集唯一核心情绪及最多一至两个次要情绪；最后确定本场如何铺垫、升级、对比或兑现本集核心情绪。若用户只提供局部剧本，只依据已提供上下文和既有台账判断，不虚构后续；若用户明确说明后续意义，以该说明为最高导演依据。

核心情绪不是最激烈、最响亮或场面最大的情绪，而是对女主选择、核心关系和后续剧情影响最大的情绪；次要情绪只能铺垫、阻碍或衬托核心。把场内节拍分为S级核心情绪证据、A级主要情绪触发/转折、B级次要情绪和支持证据、C级环境建立、D级功能动作。绝不平均分配：S/A级通常占可用叙事时长约50%—70%，B级约15%—30%，C/D级合计约10%—25%，再根据对白、因果、空间和表演完成度校正；比例不足时增加生成单元，不删台词、不压缩核心情绪。

情绪审核不等于检查有没有微表情。必须同时检查本集核心与次要情绪、本场使命、情绪原因与对象、内在冲突、变化过程、行动证据、对方反馈、关系增量、跨场兑现，以及时长、镜头数、特写和运镜是否真正与重要性匹配。先对整场分配总时长，再拆30秒单元；不得让每个单元机械重复环境建立或平均拥有同样比例。直接生成模式只在后台执行；审核模式先输出简洁`【整集与本场情绪审核】`再给正式提示词。

### 3. 判定核心正场、正场辅助段与过渡戏

完成场级情绪导演图后、拆镜和资源分配前，必须读取 [scene-type-classification.md](references/scene-type-classification.md)。分别在场级、段落级和镜头级判断内容属于核心正场、正场辅助段还是过渡戏；不得按场面大小、动作数量、台词长度、制作难度、原稿S级标签或剧本顺序判断轻重。

先执行女主选择与关键关系硬门，再在未触发硬门时使用启发式计分。男女主同场默认是正场候选，但场内无关系增量的拿物、走位、开关门等仍可判为辅助或过渡；男主无台词、离场、昏迷或不在画面内，也不得自动降级，只要女主行为证明对他的感情、责任或选择，仍按关系正场或选择正场处理。人物言行相反是高价值正场信号，必须保护原台词、过程表演、句尾余波、1—2秒反应及言行矛盾。

核心正场获得约50%—70%的可用叙事时长，正场辅助段约15%—30%，环境与过渡合计约10%—25%，再按对白、因果和空间校正。简单过渡优先约1秒，只有路径或结果确需展示时才延至1.5—3秒；结果清楚后立即切走。内容不足30秒自然结束，不得增加走路、空镜、重复动作或无意义停顿。用户要求审核、对比或优化时，严格输出该参考文件中的`【场级定位】→【段落分类】→【正场依据】→【资源失衡】→【修改方向】`；直接生成提示词时只在后台执行，不增加最终控制块。

### 4. 建立前期分析包

完整剧本至少提取：

- 一句话卖点、题材、时代、地域、受众和整体 3D 美术方向。
- 女主欲望、外部目标、内在缺口、底线、成长弧。
- 核心关系张力、情感承诺、爽点/虐点/甜点/悬念。
- 每集开场钩子、升级点、情绪峰值、反转和尾钩。
- 角色、服装、场景、道具、特效的资产清单与复用计划。
- 需要重点制作的名场面、口型镜头、群像镜头和高风险镜头。

女频叙事与视觉决策必须遵循 [narrative-style.md](references/narrative-style.md) 与 [female-oriented-adaptation.md](references/female-oriented-adaptation.md)。

### 5. 建立资产圣经

为复现两次以上、推动剧情或承担情感意义的角色/服装/场景/道具建立锚定卡。使用稳定编号：

- 角色：`CHAR-001`
- 服装：`LOOK-001-A`
- 场景：`LOC-001`
- 道具：`PROP-001`
- 特效：`FX-001`

完整字段、模型表和提示词规范见 [asset-bible.md](references/asset-bible.md)。正式分镜只引用资产编号与当下状态，不重复整张资产卡。

### 6. 建立连续性台账

逐场更新：

- 角色所在位置、服装层级、发型、妆容、伤痕、泪痕和污损。
- 道具归属、位置、朝向、完整/损坏状态。
- 场景时段、天气、灯光、门窗开合和可移动物件位置。
- 关系状态、已知信息与尚未揭露的信息。
- 跨场情绪因果：本场欲望显形、后续两难、选择代价与最终行动兑现；不得因为已知结局而演弱前置欲望，也不得提前演成最终决定。

已损坏、遗失或被带走的物件不得无因恢复。创伤、换装、特效和接触必须有可见因果。

### 7. 按音频和生成能力拆段

优先级：

1. 成品配音或时间码。
2. 用户指定时长。
3. 中文估算。

无音频时可运行：

```bash
python scripts/estimate_zh_duration.py --text "待估算的中文台词"
```

估算只用于角色对白、角色内心音和明确旁白排产，最终以配音波形为准。纯画面镜头按动作完成时间、情绪停留和信息可读时间确定，不得按未标记为可听声音的叙述文字朗读时长反推。不要沿用英文“逐词计时”。每个最终提示词对应一个最长30.0秒的生成单元，内部可包含多个切镜；0.0秒直接进入叙事内容，叙事内容最多29.5秒，最后0.5秒为静止大全景站位锚定。普通叙事镜头不得超过3.0秒；简单过渡优先0.8–1.2秒，情绪特写优先2.0–3.0秒。核心关系双方独处、发生暧昧、试探、克制触碰、重要对视或关系情绪转折，且切镜会破坏情绪累积时，30秒单元最多允许两个3.1–5.0秒长镜头；两者不得相邻，必须分别推进不同情绪节拍且各自包含至少四个可见阶段。场景切换、声音连续性、动作结果点、语义重音、听者反应、情绪落点和30秒上限共同决定切点。不得为塞进30秒修改、删减、加速、重复或重新断句任何剧本语言。

### 8. 生成30秒视频提示词

`v9.4.0`最终提示词输出格式为本节最高优先级。只输出以下全局块并按顺序排列：`【负向】→【原生音频】→【音色锁】（有开口角色时）→【画风锁】→【参考图职能分派】（有图时）→【空间锁】→【群演】→【承接·起始状态】→逐镜正文`。不得在最终成品中额外输出`【生成单元】`、`【成片取用】`、`【剧本语言原文最高优先级锁】`、`【镜头主体实体化锁】`、`【情绪链】`、`【镜头呼吸锁】`、`【量化运镜锁】`、`【台词表演与节奏锁】`、`【声音策略】`、`【结束状态与站位锁】`或`【状态变化】`。这些规则继续在后台执行，其实际信息分别合并进全局块、逐镜标题、`光`、`画面`、`音效`和`[台词]/[内心音]/[旁白]`。

每个叙事镜头固定输出：`**镜一（X.Xs）｜景别·明确取景范围·焦段｜具体机位｜量化运镜或固定**`，下一行依次输出`光　...`、`画面　...`、`音效　...`；存在角色对白、内心音或明确旁白时，再输出对应的`[台词]`、`[内心音]`或`[旁白]`行。镜头标题必须使用中文镜号、秒数、景别、具体可见主体/取景范围、焦段、机位方向与高度，以及完整量化运镜数据；固定镜头写`固定`。不要使用表格、代码块、项目符号、`【画面内容】`、`【声音内容】`或`【状态变化】`。

主体字段执行格式硬门槛：除结尾0.5秒技术大全景外，每个`画面　`段的第一个分句必须直接点名一个已经确定的主要叙事焦点，例如具体角色姓名、该角色的具体身体部位、具体道具或具体空间部件；不得先写机位、光线、环境或抽象判断。随后写明区域/层次、朝向、开镜状态、具体触发、确定的面部/视线变化、确定身体动作和镜末状态。成品不得保留斜杠、备选项、占位符或“人物、在场人物、某人、声音来源或人物”等泛称。

本节和 [final-video-prompt-template.md](references/final-video-prompt-template.md) 对最终呈现格式具有最高优先级。其他参考文件中的“【画面内容】”统一解释为本格式的`画面　`段，“【声音内容】”统一解释为`音效　`与声音原文行；旧控制块仅表示后台检查事项，不得恢复为额外输出字段。

先读 [scene-emotional-priority-audit.md](references/scene-emotional-priority-audit.md)、[scene-type-classification.md](references/scene-type-classification.md)、[review-standards.md](references/review-standards.md)、[video-prompt-30s-format.md](references/video-prompt-30s-format.md)、[final-video-prompt-template.md](references/final-video-prompt-template.md)、[storyboard-spec.md](references/storyboard-spec.md)、[emotion-action-performance.md](references/emotion-action-performance.md)、[dialogue-action-rhythm.md](references/dialogue-action-rhythm.md)、[spatial-direction-composition.md](references/spatial-direction-composition.md)、[camera-variety-and-angle.md](references/camera-variety-and-angle.md) 和 [quantified-camera-motion.md](references/quantified-camera-motion.md)。直接生成提示词时不再使用 output-templates.md 中的旧逐镜模板。每个生成单元必须明确：

- 生成单元编号、生成素材总时长（不超过30.0秒）和成片取用区间。
- 内部镜头标题最前面的时长与标准景别，格式为 `镜头二（X.X秒）【景别：近景】`；普通镜头X.X不得超过3.0秒，符合条件的核心关系长镜头可为3.1–5.0秒。
- 剧本行覆盖、动作/场面说明执行方式与合法声音类型。
- 时长及依据。
- 资产引用与状态增量。
- 重要角色音色锁：年龄感、声线质地、口音、自然语速与基础音量跨镜一致，情绪只改变允许变化的气息、重音和强度。
- 每个内部镜头只输出一个`光　`段、一个`画面　`段、一个`音效　`段和实际存在的声音原文行；机位、焦段与主运镜写进镜头标题，主体与资产状态、逐时段表演、站位距离、场景交互、连续性和镜末状态写进`画面　`段。
- 使用主运镜时的量化数据：类型、方向、总位移或总角度、持续时间、平均速度、缓入缓出、启动触发点、停止点、焦距与轴线稳定结果。
- 角色台词、角色内心音、明确旁白及归属、口型、剧情内声源、环境声、音效、无BGM/配乐锁和剪辑建议。

不要输出“首帧”“尾帧”“关键帧”“动作提示词”“情绪提示词”或旧版【画面内容】【声音内容】【状态变化】字段。所有可见、可运动、可生成的信息必须合并进逐镜`画面　`段，按照镜头内发生顺序写成可直接复制执行的连贯提示词；光线放进`光　`段，环境声与动作音效放进`音效　`段，剧本语言只放进对应声音原文行。

后台执行镜头主体实体化锁但不输出该锁名。除结尾0.5秒技术大全景外，每个`画面　`段的第一个分句必须确定一个具体主要叙事焦点：人物镜头写角色姓名或该角色的具体身体部位；物件或环境插镜写具体道具、门窗、家具或空间部件。继续写明区域/层次、朝向、开镜状态、具体触发、确定面部/视线变化、确定身体动作和镜末状态。画外声音本身不能成为可见主体；无合理可见反应时并入相邻镜头。严禁泛称、备选、占位符和评价句；任一镜头缺少具体主体、确定动作或镜末状态时必须重写。

每个生成单元强制采用`一个或多个内部叙事镜头 → 结尾0.5秒完全静止全景`。第一镜直接进入剧情，不添加开头全景。结尾全景使用同样的镜头标题与`光／画面／音效`格式，在`画面　`段逐名写动作完成后的真实新站位并全部静止，不复位、不眨眼、不呼吸起伏、不摆动、不运镜、不承载任何语言；该0.5秒保留在生成源素材中供同场景下一条锚定，正式成片可裁掉。

收到人物站位关系参考图时，必须读取 [reference-image-role-separation.md](references/reference-image-role-separation.md)。站位图只可提取人物前后、左右、面对方向、大致距离、与主要家具的相对位置、地面高差及动作开始站位，并先转写成文字站位。禁止继承场景、外貌服装、姿态表情、道具外观、机位景别、构图透视、光线色彩、材质或画风；站位图不得以任何形式出现在视频中。将完整职能限定与优先级内容合并进`【参考图职能分派】`的`站位　`段，不额外输出旧版固定块；实际文字站位、方向和轴线合并进`【空间锁】`，逐镜可见执行写入`画面　`段。

生成任何最终视频提示词时读取 [prompt-control-blocks.md](references/prompt-control-blocks.md)，只按其v9八个全局块输出。固定`【负向】`和`【画风锁】`核心不得删减、概括、改写或换序；专项内容只在句末追加。场景锚定、关键空间、方向、站位和轴线统一合并进`【空间锁】`；上一条锚定与开镜人物状态统一合并进`【承接·起始状态】`。参考图使用“只继承/严格锁定＋排除范围”，不得照抄示例人物、暗场、长焦、灯位或无边界的“完全照搬”。受保护语言与固定负向冲突时列为制作冲突，不修改受保护语言；非语言画面可在不改变关键剧情的前提下采用合规等价呈现。

每个主要角色在场次内必须具有完整的表演变化：`情绪起点 → 触发事件 → 短暂迟滞/停顿 → 五官局部依次变化 → 呼吸、手部或重心跟随 → 表情与动作峰值 → 对方反馈 → 回落后的新状态`。把“震惊、愤怒、悲伤、心动”等情绪词只当作后台判断；真正交给视频模型执行的过程必须直接写入每个相关内部镜头的【画面内容】，不得只停留在【情绪链】或用情绪名称代替表演。显著转折至少写出三个可见阶段，并用“起初、听到/看到后、停顿片刻、随后、最终”等时序词或实际秒点串联；明确眼睑、瞳孔/视线、眉形、鼻翼、嘴唇、下颌等部位如何先后变化，再选择一种呼吸、手部、肩颈或重心反应形成动态传导。禁止所有部位同时夸张启动，也禁止开镜即出现情绪峰值。单镜无法自然承载时，拆成连续镜头或下一个生成单元，并继承情绪阶段、坐标、朝向、重心、手部/道具、视线与尚未完成的微表情。具体规则和示例见 [emotion-action-performance.md](references/emotion-action-performance.md)。

逐镜执行“表演细节完整性硬门”。人物镜头的`画面　`段必须写出该机位真实可见的：开镜体态与朝向、明确触发、最先启动的身体部位、重心或步法、手臂/手腕/手指路径及接触点、躯干与头眼联动、动作峰值或受力反馈、惯性回收和镜末状态；表情变化必须写出原表情、触发后的迟滞、至少两处有先后顺序的五官变化、一处呼吸/肩颈/手部/重心传导及未完全消失的余波。不得用“走过去、转身、震惊、心动、情绪复杂”等概括词替代过程。若一个镜头装不下，减少动作或拆镜，不能删掉决定因果、接触和情绪可读性的关键步骤；镜头裁切范围外的部位不得虚写。

后台执行镜头呼吸规则，不输出`【镜头呼吸锁】`。从0.0秒开始的全部叙事镜头保持极其轻微、低频、平滑的摄影机浮动，总振幅0.5–1.5厘米、周期3–5秒；把实际数据写在每镜`画面　`段末句。它不计作唯一主运镜，不改变主运镜轨迹、轴线、景别或安全构图；结尾0.5秒全景振幅为0厘米并绝对静止。

后台执行量化运镜规则并读取 [quantified-camera-motion.md](references/quantified-camera-motion.md)，不输出`【量化运镜锁】`。逐镜自主判断固定或运动：先把人物表演、构图、光影和空间层次做完整，再判断相机运动是否能新增叙事信息、引导视线、揭示关系距离或放大明确情绪拐点；若不能，就使用有意图的固定机位。人物表演偏弱时先补表演，不能只靠运镜遮掩；情绪变化只是判断依据，不自动触发运镜。使用主运镜时只用一种低幅运动，并在镜头标题写全类型、方向、总厘米/角度、持续时间、平均速度、缓入、缓出、剧情启动点和停止点，数据自洽且误差≤10%；不数字变焦、不跨景别、不越轴。结尾0.5秒全景固定。

后台同时读取 [camera-variety-and-angle.md](references/camera-variety-and-angle.md)。镜头组不得全部平视、正面、居中或固定：根据权力、脆弱、暧昧和选择分别判断平视、5°—20°轻俯或5°—15°轻仰，角度必须有叙事理由且不造成短焦畸变。真正的固定镜头只留给关键对视、触碰前迟疑、台词落点、强表演和稳定权力构图；普通“准固定”镜头可使用2°—5°、横向弧位5—15厘米、持续2—3秒的极轻微单侧环绕形成视差，仍须量化且不得越轴。一个30秒单元至少采用三类不同的镜头策略，但不得为了变化强行运镜；连续两个真正固定镜头必须有明确表演理由，连续三个镜头不得重复同一主运镜。相邻镜头除景别跳级外至少改变机位高度、水平角度、构图重心、前景遮挡、焦点、关系层次或运动状态中的两项。

镜头时长必须形成长短句。简单过渡默认约1秒，情绪特写默认2—3秒，普通对白/反应按自然语义和动作完成点使用1.2—2.8秒，核心关系长镜头3.1—5秒。禁止三个连续叙事镜头时长相同或只相差0.1秒，禁止把整条切成整齐的“每镜约2秒”；时长只因信息量、表演阶段和声音波形而变化。

后台执行台词表演与节奏规则，不输出同名控制块。人物开口时在`画面　`段同步写准备反应、台词推进中的微表情/视线/呼吸与小幅动作、语义重音动作峰值和句尾余波；在`[台词]`行的引号外写具体情绪声线和跨镜/口型说明，引号内只放逐字原文。成品配音优先；无音频时用自然普通话约3.4–4.2汉字/秒排产。普通镜头≤3.0秒；只有符合条件的核心关系长镜头可为3.1–5.0秒。普通长台词在自然语义节点切至已点名反应主体或具体物件，音轨连续、不漏字、不重字、不换声。具体规则见 [dialogue-action-rhythm.md](references/dialogue-action-rhythm.md)。

对单人连续台词额外执行“约10个汉字一次视觉切换”的审核门，汉字计数不含标点：在接近第10个汉字的自然语义节点切到听者反应，必要时切关键道具、手部或环境主体。此规则只改变画面，不得把台词重新断句、拆成新台词、重复原句或中断音轨；听者反应必须晚于触发词。

逐镜执行审核表的镜头语言要求：双人对手戏优先内外反打、过肩、侧后方和三分之四角度，减少双人中景和叙事全景；过肩镜头必须在`画面　`段写清前景肩背、中景人物及可见角度、背景场景/道具；减少平视、单人大脸特写和单人正面构图。只描述当前机位真实可见的信息。运镜由剧情价值决定：跟随走位、揭示信息、关系距离改变、视线转移或需要把细微情绪推到可读范围时，可选择有触发点的低幅缓推、缓拉、跟随、横移、摇摄、弧形环绕或小幅升降之一；男女主对视、触碰前的迟疑、台词落点后的余波、强微表情或权力构图已经成立时，优先固定，让表演和停顿承压。镜头呼吸不是主运镜。不得为了“高级感”让每个镜头都运动；结尾0.5秒技术大全景必须绝对静止。

每个镜头组首个叙事镜头必须承接上一镜的动势、视线、站位、轴线、景别机位、道具和情绪余波，同时不得复制同一机位。若当前镜头组不是场景结尾且下一组仍在同一场景，最后一个叙事镜头必须用过肩双人、双人近景或带前后景的双人关系构图重新交代主关系站位；该关系镜头之后仍保留结尾0.5秒完全静止大全景技术锚定。

同一地点、连续时间内的人物名单发生变化时，强制输出`【人物出入场连续性锁】`并读取 [entrance-exit-continuity.md](references/entrance-exit-continuity.md)。退场人物必须写清当前起点、转身/起步、相对家具路线、经过层次、出入口或画框边缘、完全离画/跨过门槛、携带道具和门的最终状态；入场人物必须写清画外来源、进入口、首次显露、跨门槛/进入画框、相对家具路线、停步点、最终朝向、与在场人物距离及携带道具。锁内规划必须逐拍落实到相关镜头【画面内容】，不能只写“某人离开”“某人走进来”或只记录变化后的站位。一个3秒镜头无法自然完成时拆成多个内部镜头或下一个生成单元，后一镜从前一镜的身体、步态、方向和门窗状态继续；禁止跳过中段轨迹、瞬移、凭空消失、凭空出现或在遮挡后无因换位。

连续内部镜头主画面主体相同时，景别不得相同或相邻，必须至少跨两档；中景后不得接中景、中近景或全景，可接近景、特写、远景或大远景。生成单元结尾0.5秒大全景不参与跳级计算。若台词跨切镜连续，优先切听者反应、关键道具、手部或环境主体，并保持音轨无缝连续。仅改变角度、机位或运镜不能替代景别跳级。

原剧本语言必须逐字逐标点保留。严禁为节奏、时长、口型或情绪效果新增、删除或调整对白、内心音、明确旁白及剧情内声音。剧本明确写出的旁白、解说或画外讲述必须进入成片音轨并按原声源、原文、原顺序执行，不得仅因声音类型而列为阻断项；剧本未明确标注的旁白与剧本说明朗读不得进入成片音轨。

后台执行空间方向与审美构图规则并读取 [spatial-direction-composition.md](references/spatial-direction-composition.md)。先建立场景俯视拓扑、人物坐标、身体朝向、头部偏转、视线目标、说话对象、主轴与摄影机轴侧。人物开口时，`画面　`段必须明确身体朝向、头部转向、眼神落点与实际听者位置，确保嘴部朝向与声音投射方向一致。若开镜时背向或侧背听者，必须先写可见的转头、转肩或转身过程再开口；只有剧本明确要求背身、隔门或对画外目标说话时例外，并写清声源方向。禁止身体朝画左、听者在画右却无转动直接朝相反方向说话。

每镜先设计构图再决定运镜：锁定视觉中心、主体落点、眼线高度、视线空间、头顶留白、前中后景、遮挡、负空间用途和背景几何。避免无理由居中、头顶留白过大、脸贴边、视线撞墙、地平线切颈、家具切头、关节处截肢和双人等高并排证件照构图。相邻叙事镜头除景别跳级外，还应改变构图重心、视点高度、前景遮挡、关系层次或焦点调度中的至少两项，但不得破坏轴线和场景几何。

运镜节奏按镜头组设计。连续三个叙事镜头不得使用同一种主运镜；相邻镜头避免同方向、同幅度、同速度的推拉或摇摄。优先采用“固定承压—低幅运动揭示—固定落点”或“跟随进入—关系构图停住—反打承接”等节奏。焦点调度、前景遮挡变化、演员走位和构图重心变化可承担视觉变化，不必全部依靠摄影机移动；任何变化都必须服务女频情绪与关系信息。

核心关系长镜头只在男女主或核心关系双方独处、暧昧升级、重要对视、克制触碰、试探或关系情绪转折时使用。一个30秒单元最多两个，时长各3.1–5.0秒，优先3.2–4.5秒；两个长镜头不得相邻，必须服务不同情绪节拍，并各自连续呈现至少四个阶段。若存在第三人打断、空间信息需重新交代、表演无法持续或只是延长凝视，仍按普通镜头≤3秒拆镜。长镜头不得降低自然语速，不得新增台词，不得叠加两种主运镜。

### 9. 后台质检后交付

逐项执行 [review-standards.md](references/review-standards.md) 的 `RS-01` 至 `RS-20`，再执行 [qc-checklist.md](references/qc-checklist.md)。修复所有阻断项再输出，不要把内部推理写给用户。若原文自身存在未确认的阻断矛盾，明确列出并停止在受影响范围之前。

## 核心生成纪律

- 使用中国语境、中文界面、国内礼仪和题材对应的建筑服饰；古装题材按明确朝代或架空设定执行。
- 保持同一角色的脸型、五官比例、发际线、发型轮廓、体型、服装结构和配饰稳定。
- 禁止直接复制现实明星面孔；可描述气质与骨相方向，但生成原创角色。
- 只写模型可见、可运动、可听见或可剪辑的信息。把“心碎、后悔、心动”等抽象词转为表情、姿态、节奏和环境反应。
- 全部剧情必须由镜头内事件、角色行为及源剧本已有的对白、角色内心音、明确旁白和剧情内声音推进。不得自行新增解说旁白补时间线或交代反转。
- 任何角色语言都必须能在源剧本中找到逐字一致的唯一出处；不得为了画面完整、情绪强化或镜头衔接补写一句话或一个语气词。
- 一镜只承载一个主叙事动作。复杂接触按“接触前 → 接触瞬间 → 接触后”拆分。
- 动作必须遵循人体链条：当前体态 → 核心部位启动 → 重心转移 → 四肢/躯干联动 → 动作峰值或接触反馈 → 惯性回收 → 可承接状态。
- 每个短时段优先只选 1 个眼神变化、1 个嘴部/呼吸细节和 1 个手部/重心动作；情绪顶峰也只保留一个主动作与一个生理反应。
- 双人镜头必须先区分主动方与承接方，动作按因果错开，禁止双方同步抢动作；所有入画人物仍需有可见状态。
- 保持 180 度轴线、视线匹配、动作匹配和左右方向连续。需要故意越轴时必须标明叙事目的。
- 不在视频生成提示词中混入淡入、闪白、黑场等后期命令；将其写入剪辑建议。
- 不使用“同上”“参考前镜”等不可独立执行的描述。每镜应能脱离上下文被生产人员理解。
- 每镜必须主动选择固定、焦点调度或运动，不得机械套用；明确情绪变化不等于必须运镜，强表演、关键对视、触碰前停顿和台词余波允许并常常更适合固定。采用运镜时必须有新增叙事价值与画面内触发点，并保持低幅、平滑、单一、量化；连续三个叙事镜头不得使用同一种主运镜。
- 每镜只选择一种主运镜；运镜必须服务于情绪或动作信息，不得同时堆叠推进、横移、环绕、升降等冲突要求。
- 同一内部镜头只声明一个景别；只有单元结尾0.5秒大全景是强制技术定位段，不视为叙事镜头。不得添加开头大全景。内部运镜若跨入另一景别，拆成新内部镜头。
- 群像镜头要区分人物轮廓、站位和动作；不要让背景角色复制脸、同步动作或静止呆立。
- 未成年人不得成人化或性化。亲密戏强调关系、同意、情绪和镜头克制。

## 渐进读取

- 分析题材、女频节奏与视觉风格时读取 [narrative-style.md](references/narrative-style.md)。
- 设计或审核本集核心/次要情绪、场次使命、时长权重和跨场铺垫兑现时读取 [scene-emotional-priority-audit.md](references/scene-emotional-priority-audit.md)，先完成“整剧—本集—本场”推导与S/A/B/C/D资源分配。
- 完成场级情绪导演图后，或审核正场、辅助段、过渡戏、女主选择硬门、男女主同场、单方关系行为、言行冲突与资源轻重时读取 [scene-type-classification.md](references/scene-type-classification.md)，再进入拆镜。
- 创建或核对角色、服装、场景、道具时读取 [asset-bible.md](references/asset-bible.md)。
- 收到站位关系参考图或多类参考图时读取 [reference-image-role-separation.md](references/reference-image-role-separation.md)，先完成职能隔离与文字站位锁。
- 生成最终可复制视频提示词及其控制块时读取 [prompt-control-blocks.md](references/prompt-control-blocks.md)。
- 组装最长30秒、含多个内部切镜的视频生成单元时读取 [video-prompt-30s-format.md](references/video-prompt-30s-format.md)。
- 输出最终可直接投入视频模型的提示词时读取 [final-video-prompt-template.md](references/final-video-prompt-template.md)，该模板高于 output-templates.md 的旧逐镜格式。
- 处理任何剧本、台词、内心音或剧情内声音前读取 [script-verbatim-lock.md](references/script-verbatim-lock.md)，交付前执行双向逐字核对。
- 为台词设计自然语速、情绪声线、口型、动作配合、普通3秒切镜、核心关系长镜头和听者反应时读取 [dialogue-action-rhythm.md](references/dialogue-action-rhythm.md)。
- 同一连续场景人物名单发生增减、角色进入或离开空间时读取 [entrance-exit-continuity.md](references/entrance-exit-continuity.md)，生成出入场锁并把轨迹落实到【画面内容】。
- 为角色生成完整情绪、动作、站位和机位时序时读取 [emotion-action-performance.md](references/emotion-action-performance.md)。
- 判断人物表演是否偏弱、选择主运镜并输出厘米/角度/速度等执行数据时读取 [quantified-camera-motion.md](references/quantified-camera-motion.md)。
- 设计人物说话方向、视线匹配、场景几何、镜头组构图与运镜变化时读取 [spatial-direction-composition.md](references/spatial-direction-composition.md)。
- 拆镜或编写统一【画面内容】时读取 [storyboard-spec.md](references/storyboard-spec.md)。
- 输出审校报告、资产卡或非视频模型交付物时读取 [output-templates.md](references/output-templates.md)。
- 任何正式交付前读取 [qc-checklist.md](references/qc-checklist.md)。
- 设计镜头前和正式交付前都读取 [review-standards.md](references/review-standards.md)，逐项通过 `RS-01` 至 `RS-20`。
